关于我，和这个博客

我是做 Java 后端的，正在往 AI 应用工程师转。这个博客记两条线：一条是技术，一条是生活。

我是谁

Java 后端开发，正在往 AI 应用工程师转型。平时做的事：把 Java 业务系统和 Python AI 推理服务接在一起，跑计算机视觉和视频分析的流水线，用的技术有 YOLO、PaddleOCR、RabbitMQ、Redis、MySQL、Vue，还有 WVP、GB28181、ZLMediaKit 这些视频流的东西。

现在手上有两个在做的项目：一个是货车视频识别系统，一个是 DeepSeek 的通用视频 OCR 插件。进展和踩过的坑，都会写在这个博客里。

这个博客写什么

技术写给未来的自己，生活写给现在的自己。技术文章只写能落地的东西：YOLO 怎么跑起来、OCR 怎么接进智能体、Java 后端怎么和 AI 推理服务配合，踩过的坑和真正跑通的做法都会写下来，不写只讲概念的空话。

生活文章写具体的日子：一条路、一顿饭、一个清晨。

写博客的规矩只有一条：写具体的东西。不写“要努力”这种空话，写今天改了哪一行代码、调了哪个参数、走了哪条路、做了哪道菜。具体，才经得起回看。

正在做的项目

  • 货车视频识别系统——YOLO 车辆检测 + 车牌 / 车门 OCR，RTSP 流处理，带框推流。
  • DeepSeek 视频 OCR 插件——给 DeepSeek Harness 用的通用视频 OCR 工具插件，视频抽帧 + PaddleOCR，按时间戳返回文字。
  • 游戏合集——几个能直接在网页上玩的小游戏。
